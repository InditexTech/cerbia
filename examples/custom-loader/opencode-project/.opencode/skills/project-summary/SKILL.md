# Project summary

Create a short summary of Maple Harbor community event notes.

## Process

1. Capture the event overview, confirmed dates, and named owners.
2. List open questions separately from confirmed decisions.
3. Identify the next action for each owner when the notes provide one.
4. Report missing information instead of inventing details.

## Output

Use the sections **Overview**, **Decisions**, **Open questions**, and **Next actions**.
Keep the wording factual and suitable for a public planning meeting.
