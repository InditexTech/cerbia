# Volunteer brief

Create a short briefing from approved event notes.

| Section | Include |
| --- | --- |
| Event snapshot | Purpose, date, and location when available |
| Volunteer roles | Named responsibilities and handoffs |
| Preparation | Materials and unanswered questions |

Keep the briefing factual. When information is absent, note the gap for the
planning coordinator.
