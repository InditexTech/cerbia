# Examples

Choose an example, then follow the setup and execution steps in its README.

- [Programmatic usage](programmatic-usage/README.md): Build a security gate directly in Python and inspect safe and blocked verdicts.
- [CLI usage](cli-usage/README.md): Run the [simple](cli-usage/simple.cerbia.yaml) and [cascade](cli-usage/cascade.cerbia.yaml) configurations through the `cerbia` command-line interface.
- [Custom loader](custom-loader/README.md): Implement a project-local loader and scan an OpenCode project fixture.
- [LangChain Agent Guardrail](langchain-agent-guardrail/README.md): Intercept and guard multi-agent LLM prompts, tool invocations, and responses with CerbIA callback handlers.
- [FastAPI BIM Guardrail](fastapi-bim-guardrail/README.md): Demonstrate input and output checks in a FastAPI endpoint with a simulated model response.

For installation and the full command surface, see the [getting started guide](https://inditextech.github.io/cerbia/latest/main/quickstart/)
and [CLI reference](https://inditextech.github.io/cerbia/latest/main/cli/).
