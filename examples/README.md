# Examples

Choose an example, then follow the setup and execution steps in its README.

- [Programmatic usage](programmatic-usage/README.md): Build a security gate directly in Python and inspect safe and blocked verdicts.
- [CLI usage](cli-usage/README.md): Configure and run a reusable security policy through the `cerbia` command-line interface.
- [Custom loader](custom-loader/README.md): Implement a project-local loader and scan an OpenCode project fixture.

For installation and the full command surface, see the [getting started guide](https://inditextech.github.io/cerbia/prerelease/main/quickstart/)
and [CLI reference](https://inditextech.github.io/cerbia/prerelease/main/cli/).
