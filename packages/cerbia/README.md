# cerbia

The metadata-only CerbIA installation selector. It installs `cerbia-core` but does not provide a Python import package.

```bash
pip install "cerbia[cli]"
```

Choose `cli`, `ml`, `presidio`, `protectai`, or `all` extras as needed. Read the [full package reference](https://inditextech.github.io/cerbia/latest/cerbia/).
