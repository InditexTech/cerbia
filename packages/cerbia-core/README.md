# cerbia-core

The CerbIA core pipeline, imported as `cerbia.core`.

```bash
pip install cerbia-core
```

Use `SimpleGateConfig` or `CascadeGateConfig` and `Runner` to build a gate; `CerbIAConfig` is their discriminated union. Read the [full package reference](https://inditextech.github.io/cerbia/latest/cerbia-core/).
