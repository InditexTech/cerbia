= Scanners
:description: Browse scanners for hidden text, prompt injection, PII, secrets, URLs, keywords, and other findings.
:page-tags: Reference, Components

Scanners inspect one entry at a time and return a `ScanOutcome` with a risk score, rationale, and optional match spans. The pipeline adds each scanner's configured severity and action to form a finding. Only `BLOCK` findings affect the aggregate verdict; other findings remain visible for review.

Every scanner accepts `severity`, `action`, and `content_types`, although their defaults differ. `content_types: null` accepts every entry type. An incompatible scanner is skipped and recorded rather than executed.
