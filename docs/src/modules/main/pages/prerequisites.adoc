later and a CerbIA installation with the `cli` extra.

== Requirements

* Python 3.12 or later.
* `pip` or another Python package installer that can install packages from
  PyPI.

== Installation

Install CerbIA with CLI support in the environment where you plan to run it:

[source,bash]
----
pip install "cerbia[cli]"
----

The `cli` extra provides the `cerbia` executable. CerbIA also offers optional
extras for local ML, Presidio, and ProtectAI integrations; see
xref:reference-overview.adoc[Reference] for package entry points.
