`cerbia-protectai` provides
`cerbia.protectai.scanners.ProtectAIPromptInjectionScanner`, an optional
classifier-backed prompt-injection scanner. It depends on `cerbia-ml` for model
and tokenizer loading.

```bash
pip install cerbia-protectai
```

## Runtime requirements

The scanner loads pinned model and tokenizer artifacts through a Hugging Face
classification runtime. `local_files_only` defaults to `true`, so deployments
must provision the required cache before construction. Set it to `false` only
when downloads from the Hub are acceptable.

The scanner supports whole-text classification (`match_type: full`) and
overlapping windows (`match_type: chunks`). Chunked mode uses `chunk_size: 256`
and `chunk_overlap: 25` by default, then returns the highest injection score
observed across all windows.

```yaml
scanners:
  - scanner: cerbia.protectai.scanners.ProtectAIPromptInjectionScanner
    init_args:
      match_type: chunks
      local_files_only: true
```

See [ProtectAI prompt injection scanner](../components/scanners/prompt-injection-protectai.mdx)
for the complete constructor reference and
[cerbia-ml](cerbia-ml.mdx) for artifact behavior.
