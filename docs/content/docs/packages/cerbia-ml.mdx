`cerbia-ml` provides `cerbia.ml`, a small runtime layer for pinned model
artifacts and text-classification adapters. It is optional: installing it alone
does not add a CLI command or a scanner to a core configuration.

```bash
pip install cerbia-ml
```

## Artifact coordinates and sources

`ArtifactCoords` identifies an immutable artifact with a repository reference,
a required 40-character revision, and optional subfolder or filename.
`ArtifactSource` implementations resolve those coordinates to local paths.

`HuggingFaceHubSource` uses the Hugging Face cache. `is_available()` checks
whether a requested artifact path already exists; `fetch()` materializes the
requested snapshot and can limit downloads to the requested subfolder or file.

## Classifier adapter

`HuggingFaceClassifierAdapter` loads a tokenizer and ONNX sequence-classification
model, then returns validated classification results for a batch of strings.
`local_files_only: true` restricts both loads to cached assets. Set it to
`false` only when runtime download access is appropriate for the deployment.

This package is the dependency foundation for
[cerbia-protectai](cerbia-protectai.mdx). See [Packages](index.mdx) for the
complete package relationship map.
