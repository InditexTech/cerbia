`cerbia-core` provides `cerbia.core`, the configurable pipeline used by every
CerbIA integration: entries, loaders, preprocessors, scanners, score
aggregators, configuration models, `Runner`, and `SecurityGate`.

```bash
pip install cerbia-core
```

## Minimal Python pipeline

```python
from cerbia.core.config import CerbIAConfig, LoaderConfig, ScannerConfig, ScoreAggregatorConfig
from cerbia.core.runner import Runner

config = CerbIAConfig(
    name="inline",
    loaders=[LoaderConfig(loader="cerbia.core.loaders.TextLoader", init_args={"texts": "hello"})],
    scanners=[ScannerConfig(scanner="cerbia.core.scanners.KeywordScanner")],
    score_aggregator=ScoreAggregatorConfig(
        score_aggregator="cerbia.core.score_aggregators.MaxScoreAggregator"
    ),
)
result = Runner(config).scan()
```

`Runner` requires at least one loader and scanner. It applies preprocessors in
order, then evaluates each resulting entry through the configured scanner set.
`result.entry_results` contains per-entry findings; `result.is_safe` summarizes
the complete run.

The package has no optional ML or NLP runtime dependency. Those capabilities
live in separate packages so core-only deployments remain focused on local
pattern and heuristic components.
