`cerbia-presidio` provides
`cerbia.presidio.scanners.PresidioPiiScanner`, an optional English NLP-based PII
scanner backed by Presidio and the `en_core_web_sm` spaCy model.

```bash
pip install cerbia-presidio
```

## Runtime behavior

The scanner creates a Presidio analyzer configured for English. By default it
requests every entity type supported by that analyzer; provide `entities` to
limit the request. It returns the highest Presidio confidence as the risk score,
reports entity match spans, and uses `BLOCK` by default.

```yaml
scanners:
  - scanner: cerbia.presidio.scanners.PresidioPiiScanner
    init_args:
      entities: ["EMAIL_ADDRESS", "PHONE_NUMBER"]
```

The distribution declares the analyzer and language-model dependencies, but
model initialization still occurs when the scanner is constructed. Use
`cerbia-core`'s regex-based `PiiScanner` when an NLP runtime is not appropriate.
Read [Presidio PII scanner](../components/scanners/pii-presidio.mdx) for the constructor
reference.
