title: "CerbIA"
description: "Overview of CerbIA's security-gate pipeline for evaluating AI agents' inputs and outputs."
---

CerbIA composes security gates around AI agents' inputs and outputs. Configure
loaders, preprocessors, scanners, and score aggregators to evaluate content and
return an actionable verdict.

Start with [Getting started](getting-started.mdx), then use
[Configuration](configuration.mdx) to define a pipeline. The
[package reference](packages/index.mdx) documents the public Python namespaces;
optional capabilities are available through the CLI, ML, Presidio, and ProtectAI
packages.
