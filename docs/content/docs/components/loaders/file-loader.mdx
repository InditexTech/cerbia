---
title: "FileLoader"
description: "Load UTF-8 text from files or recursively discovered directory trees, with optional suffix filters."
---

`cerbia.core.loaders.FileLoader` reads individual files and directory trees into
entries. It is useful for scanning repositories, configuration directories, and
other local text collections.

## Parameters

| Parameter | Default | Meaning |
| --- | --- | --- |
| `paths` | required | One path or a list of file and directory paths. |
| `extensions` | `null` | Optional list of suffixes to include, such as `['.py', '.yaml']`. |
| `recursive` | `true` | Whether directory paths are traversed recursively. |

A single path is normalized to a list. Direct file paths are loaded only when
their suffix passes the optional extension filter. Directory paths use `**/*`
when recursive and `*` otherwise; discovered files are sorted before loading.

Files are read as UTF-8 with replacement decoding. Invalid byte sequences are
therefore represented by replacement characters rather than causing a loader
failure. Each output entry uses the file's resolved absolute path as `source`.

Missing paths, unmatched direct-file suffixes, and directories with no matching
files produce no entries. This behavior is important when invoking the CLI with
`--file`: an empty result set is safe by definition.

```yaml
loaders:
  - loader: cerbia.core.loaders.FileLoader
    init_args:
      paths: ["src", "README.md"]
      extensions: [".py", ".md"]
      recursive: true
```
