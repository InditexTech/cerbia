---
title: "TextLoader"
description: "Load one string or an ordered list of inline strings as CerbIA entries."
---

`cerbia.core.loaders.TextLoader` converts inline strings into entries. It is the
simplest loader for application-provided values, tests, and command-line input.

```python
from cerbia.core.loaders import TextLoader

entries = TextLoader(texts=["first", "second"]).load()
```

## Parameters

| Parameter | Type | Meaning |
| --- | --- | --- |
| `texts` | `str \| list[str]` | One string or an ordered list of strings to load. |

A single string is normalized to a one-item list. The loader emits exactly one
entry per input string, in order. Each entry uses `inline[index]` as its source;
it has no field path and the default unknown content type.

```yaml
loaders:
  - loader: cerbia.core.loaders.TextLoader
    init_args:
      texts:
        - "Text to scan"
        - "Another entry"
```

`cerbia scan --text` builds an equivalent loader and replaces configured loaders
for that invocation. See [FileLoader](file-loader.mdx) for filesystem input.
