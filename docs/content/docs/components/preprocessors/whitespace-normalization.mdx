---
title: "Whitespace normalization"
description: "Normalize spaced, tabbed, and repeated whitespace patterns while preserving entry lineage."
---

`cerbia.core.preprocessors.WhitespaceNormalizationPreprocessor` removes
whitespace patterns commonly used to split words or hide instructions while
preserving the entry's source and lineage.

For each entry, it applies a fixed normalization sequence: replaces mid-line
tabs, de-jams letter-spaced text, collapses long space runs, and collapses long
newline runs. It returns the original entry object when no rule changes the
text; otherwise it creates a derived entry and records the applied
transformations in `metadata.preprocessors["whitespace_normalization"]`.

## Parameters

| Parameter | Default | Meaning |
| --- | ---: | --- |
| `max_consecutive_spaces` | `6` | A run of at least this many spaces is collapsed to one space. |
| `max_consecutive_newlines` | `6` | A run of at least this many newlines is collapsed to two newlines. |

```yaml
preprocessors:
  - preprocessor: cerbia.core.preprocessors.WhitespaceNormalizationPreprocessor
    init_args:
      max_consecutive_spaces: 6
      max_consecutive_newlines: 6
```

Run this preprocessor before text-oriented scanners when inputs can contain
letter-spaced words, excessive blank space, or tab-based obfuscation. It
preserves entry count and ordering. See [Speculative decoding](speculative-decoding.mdx)
for decoding-based transformations.
