---
title: "Preprocessors"
description: "Transform loaded entries before scanning with decoding and whitespace-normalization preprocessors."
---

Preprocessors transform loaded entries before scanners run. Core exports
`SpeculativeDecodingPreprocessor` and `WhitespaceNormalizationPreprocessor`.
Their output preserves input-entry cardinality and retains preprocessing lineage
metadata. Configure them in order: the output of one preprocessor is the input
to the next.

- [Speculative decoding](speculative-decoding.mdx)
- [Whitespace normalization](whitespace-normalization.mdx)

Preprocessing is intentionally conservative. An entry that needs no change is
passed through unchanged; a changed entry keeps its source and content type and
records the original text and transformation metadata. See
[Architecture](../../architecture.mdx) for its position in the full pipeline.
